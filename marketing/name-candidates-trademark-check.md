# App name — candidates + trademark/availability check

Current: **Build Your Body** (ex-"SummerBody"). Tagline: *"Stay Focused"*. Audience 14–21,
fitness. The name must be **distinctive** (generic descriptive names are hard to protect
and easy to collide with) and **available** across App Store + trademark + domain + socials.

## Step 1 — shortlist (pick 3 to check)

Distinctive/brandable candidates (not just descriptive):

| Name | Feel | Notes |
|------|------|-------|
| **Kova** | short, ownable, gym-adjacent | invented → strong trademark, easy domain/handle |
| **Forge** | strong, "build your body" metaphor | popular word — check collisions carefully |
| **Reps** | native gym slang, very Gen-Z | short → likely taken; check hard |
| **Strive** | aspirational, clean | common — collision risk |
| **Bodykit** | playful, "build" nod | check fitness-app collisions |
| **Habitus** | habit + body double meaning | distinctive, ownable |
| **Grit** | mindset + tagline fit | common word — check |
| **Northstar / Northgym** | direction/goals | compound helps availability |

Keep **Build Your Body** as the fallback ONLY if a check shows it's clear (unlikely).

## Step 2 — run these checks on each shortlisted name (≈30 min each)

1. **App Store name search** — search the exact name in the App Store (iOS). If an active
   fitness app already uses it, drop it.
2. **UK trademark** — search the IPO register: https://www.gov.uk/search-for-trademark
   (classes 9 = software/apps, 41 = fitness/training, 44 = health). Also check the EUIPO
   (euipo.europa.eu) and USPTO (tmsearch.uspto.gov) if launching beyond the UK.
3. **Domain** — is `<name>.app` / `.com` / `.co` free? (namecheap/instant check.)
4. **Socials** — is the handle free on TikTok + Instagram (your two GTM channels)?
5. **Google** — plain search for an existing fitness brand using it.

Score each name pass/fail on all five. First name that passes all five = lock it.

## Step 3 — lock + hand off

- Record the chosen name + the date it cleared in the brain note.
- Trigger the downstream work: app icon/wordmark, App Store listing name, `site.webmanifest`
  name, in-app wordmark, marketing assets (they're holding a `[NAME]` placeholder).
- If NOTHING clears by ~18 Jul → tell marketing the safe launch date slips to September.

## Definition of done
A single name that passes App Store + trademark + domain + socials, recorded and cleared,
so marketing can print it and the store listing can be created.
