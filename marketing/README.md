# BB — Marketing

Marketing assets for **BB** (working title "Build Your Body", ex-"SummerBody" — **name not final**), the free fitness app for 14–21 y/o. Tagline: **Stay Focused**.

This folder is owned by the **MARKETING lane**. It does not touch `styles.css`, `app.js`, `backend/`, or `BuildYourBody/` (other lanes).

## Fixed context (decisions locked for these assets)

- **Markets:** UK + US.
- **Content engine:** faceless / screen-first (no talent required). Creators = amplification layer.
- **Acquisition model:** organic + creator/UGC-led. **Paid targeting to under-18s is effectively unavailable** — budget goes to creators + production, not ad auctions.
- **Brand guardrail:** effort-based, non-shaming, body-neutral. **No weight-loss / body-image angles** (off-brand + teen-policy-restricted).
- **App name:** lead recommendation is a brandable mark (see [aso.md](aso.md)); everything says "working name" until it's locked + trademark-checked, then find-and-replace across this folder.

## Before this drives real install volume (product/legal dependencies — not this lane)

- Published **privacy policy**, **data-deletion flow**, and **age gate** live (UK AADC).
- ASO age rating + privacy label accurate.
- Name trademark + App Store/Play collision check done.
