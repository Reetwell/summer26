# Summer Body Plan — Project Summary & Claude Code Handoff

## The Goal

The user wants to get in shape for a summer holiday departing **August 8th 2025**, starting the plan on **June 1st 2025** — a 10-week window.

**User stats:**
- Height: 5'11"
- Weight: 69kg (starting)
- Body type: "Skinny fat" — relatively lean weight but higher body fat and low muscle mass
- Primary goals: Lose belly fat and face fat, build muscle across the upper body (chest, abs, arms, shoulders)

**The approach:** Mild calorie deficit for 5 weeks to strip fat, then a small surplus for 5 weeks to build muscle. High protein throughout to protect and build muscle.

---

## The Plan — Three Phases

### Phase 1a — Fat Loss + Football (June 1–20, ~3 weeks)
- **Calories:** ~2,100/day (~400 below maintenance)
- **Protein:** 160g/day
- **Gym days:** 4 per week — Mon, Tue, Wed, Fri
- **Thursday:** Football training (counts as cardio — no gym)
- **Schedule:**
  - Monday: Upper body lifting
  - Tuesday: Cardio + core (20–25 min HIIT or 30 min incline treadmill walk, then 10 min core)
  - Wednesday: Lower body + core
  - Thursday: Football training
  - Friday: Full body compound
  - Saturday/Sunday: Rest

### Phase 1b — Fat Loss, Full Gym (June 21 – July 6, ~2 weeks)
- **Calories:** ~2,100/day (same deficit)
- **Protein:** 160g/day
- **Gym days:** 5 per week — football season has ended
- **Schedule:**
  - Monday: Upper body
  - Tuesday: Cardio (HIIT or incline walk)
  - Wednesday: Lower body + core
  - Thursday: Full body compound (was football — now gym)
  - Friday: Upper body
  - Saturday: Cardio
  - Sunday: Rest

### Phase 2 — Muscle Build, PPL Split (July 7 – August 8, 5 weeks)
- **Calories:** ~2,700/day (~200 above maintenance)
- **Protein:** 170g/day
- **Training split:** Push / Pull / Legs
- **Schedule:**
  - Monday: Push (chest, shoulders, triceps)
  - Tuesday: Pull (back, biceps)
  - Wednesday: Legs + abs
  - Thursday: Active rest (easy swim, walk, or light stretch — pool at Everybody Gym Knutsford)
  - Friday: Push
  - Saturday: Pull
  - Sunday: Rest
- **Key rule:** Progressive overload every week — add weight or reps

## Diet

### Macros

| Phase | Calories | Protein | Carbs | Fats |
|---|---|---|---|---|
| Phase 1 (cut) | ~2,100 | 160g | ~200g | ~60g |
| Phase 2 (build) | ~2,700 | 170g | ~240g | ~65g |

**Maintenance calories:** ~2,500/day based on user stats and moderate activity

### Food preferences

- **Cuisines:** Mexican (wraps, burritos, tacos) · Italian (pasta) · British (roasts, steak + chips)
- **Protein sources liked:** Chicken (favourite), steak/beef, salmon, turkey, starting to like eggs
- **Carbs preferred:** Wraps/bread, potatoes, sweet potato
- **Veg:** Peas, sweetcorn, carrots (main ones)
- **Breakfasts:** Overnight weetabix with Greek yogurt + protein powder (go-to) · Protein pancakes (with recipe)

### Protein pancake recipe
1. Blend 60g rolled oats into flour using blender/NutriBullet
2. Mix oat flour + 1 scoop whey protein + 2 whole eggs + splash of milk + pinch of baking powder
3. Heat non-stick pan on medium, tiny spray of oil
4. Pour small circles (~8cm), cook 2 mins each side until golden
5. Top with Greek yogurt + berries + drizzle of honey
Makes ~6 small pancakes · ~450 kcal · P: 38g C: 46g F: 12g

### Meal structure (daily)
1. Breakfast (prep night before) — overnight weetabix or protein pancakes
2. Mid-morning snack — cottage cheese, mixed nuts, or boiled eggs (not Biscoff biscuits)
3. Lunch (~20 mins to prep in morning) — chicken/turkey/steak wrap with veg
4. Pre-workout snack — banana + whey shake + creatine
5. Dinner (~40 mins) — proper sit-down meal: fajitas, pasta bake, steak + chips, roast chicken, salmon + potatoes

### Cut foods
- Alcohol (kills recovery)
- Takeaways and fried food
- Sugary drinks and juice
- Ultra-processed snacks (including Biscoff biscuits — swap for cottage cheese or nuts)
- Late-night snacking

### Sunday batch cook habit
Cook extra chicken, boil eggs, prep weetabix jars · 30 mins Sunday saves every morning Mon–Fri

## The Web App — Current State

A single-file HTML app (`SummerBodyPlan.html`) has been built with the following sections:

### 2. Meal Plan
- Phase toggle (Phase 1 / Phase 2)
- 7-day tab navigation
- Each day shows:
  - Daily totals grid (calories, protein, carbs, fats)
  - Meal cards for each meal (breakfast, snack, lunch, snack, dinner)
  - Each card has: tag, name, kcal, ingredients, prep note, macro pills
  - Tip boxes on key days
  - Protein pancake recipe built into Tuesday breakfast

### 3. Shopping List
- Phase toggle
- Category tabs: Protein · Dairy · Carbs · Veg + fruit · Supplements · Pantry
- Tappable items with checkmark toggle
- Progress bar showing checked / total
- Reset button per phase
- Tip boxes per category

### 4. Progress Tracker
- Weight log: input field, log button, list of last 5 entries with delete
- Current weight display with change from start
- Workout log: 7-day grid per week with week navigation (1–10)
  - Training days are tappable to mark done
  - Rest days are non-interactive
  - Correct training days per phase per week
- Stats row: total sessions, day streak, weeks logged
- Weight chart (Chart.js line chart, builds as entries are added)

## Design Philosophy

### Aesthetic direction
**Refined minimal** — clean, flat, warm off-white surfaces. Feels like a premium health/fitness app. Not clinical or corporate. Not over-designed. Everything feels intentional.

### Typography
- **Display/brand:** DM Serif Display (headings, brand name, large numbers)
- **Body/UI:** DM Sans (all other text — weights 300, 400, 500, 600)
- Avoid Inter, Roboto, Arial, system-ui

### Colour palette
Built around a warm off-white background with a teal/green primary, supported by blue, purple, amber, pink accents.

### Component rules
- **Borders:** Always `1px solid rgba(0,0,0,0.08)` — never heavy borders
- **Border radius:** 8px (small), 12px (default), 16px (cards), 24px (pills/toggles)
- **Cards:** White background, 1px border, 16px radius, 16–20px padding
- **Tags/pills:** Small 10px bold text, rounded, coloured background using lightest tint + darkest text from same ramp
- **Tip boxes:** Left border accent (2px), tinted background, matching text — green for phase 1 tips, blue for phase 2 tips
- **Metric/stat boxes:** Off-white background (#F7F6F3), subtle border, no shadow
- **Buttons:** Subtle border, transparent background, hover state darkens slightly
- **No gradients** anywhere
- **No shadows** (except focus rings on inputs)
- **No emojis** in UI elements — use Font Awesome outline icons only

### Navigation
- **Desktop (>680px):** Fixed top nav bar with brand name + horizontal nav links + date. Height 64px. Frosted glass effect (backdrop-filter blur).
- **Mobile (≤680px):** Top nav hidden. Fixed bottom nav bar with icon + label per section. Height 72px + safe area inset. Frosted glass.
- Active nav item uses green tinted background

### Responsive behaviour
- Max content width: 900px, centred
- Mobile breakpoint: 680px
- Totals grid: 4 columns desktop → 2 columns mobile
- Metrics grid: auto-fit minmax(140px) 
- Item grids: auto-fill minmax(210px)
- Week grids: always 7 columns (shrink font on mobile)
- Phase toggles: flex on desktop, full-width on mobile

### Interactions
- Shopping items: tap to toggle checked state (green checkmark, line-through, opacity 0.5)
- Progress bars: animated fill transition (0.25s)
- Week navigation: previous/next buttons cycle through 10 weeks
- Workout grid: training days tappable, rest days non-interactive
- All tab switches: immediate, no animation (keeps it snappy)

## Key context for Claude Code

- The user is **not a developer** — keep the codebase simple and well-commented
- The app must work as a **standalone HTML file** with no build process required (open in browser directly)
- External dependencies loaded via CDN only: Google Fonts, Font Awesome 6, Chart.js 4
- **localStorage** is used for weight log and workout log persistence — keep this approach
- The user will be using this app daily from **June 1st 2025** — it needs to be reliable and fast
- All content (meals, workouts, shopping) is **hardcoded** — no backend needed
- The app should feel like a **premium fitness app** (MyFitnessPal quality) not a basic webpage
- Test on both **desktop Chrome** and **iOS Safari** — the bottom nav and safe area insets are important on iPhone
